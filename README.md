# 定时解锁 · ScheduledUnlock 0.1

这是为 **Windows 11 x64、有密码的本地账户** 编写的原型。你设置每日时间并保存账户密码，Windows 到点后尝试解锁当前已登录、正在锁屏的桌面会话。

**程序和登录组件已成功编译，17 项请求有效性测试已通过。 已在Windows 11 的真实登录界面上验证。** 特别需要确认完整锁屏画面和密码登录画面下的自动提交都能工作。

## 使用方法

1. 把整个压缩包解压到一个文件夹。
2. 双击 `Install.cmd`，接受 Windows 的管理员权限提示。安装完成后会打开设置窗口，并创建“定时解锁”快捷方式。
3. 确认显示的是你当前登录的本地账户，输入**账户密码**。本版本不接受 PIN、指纹或人脸识别。
4. 首先点击“60 秒后测试”，在接下来 60 秒内按 `Win + L` 锁屏。
5. 如果电脑自动回到桌面，再设置每日时间并点击“启用并保存”。时间使用这台 Windows 电脑的本地时间。
6. 日后从桌面或开始菜单里的“定时解锁”快捷方式打开设置。密码框留空会沿用已有密码；改过账户密码后，应重新输入并保存。

安装本身不会启用解锁计划。关闭设置窗口后，已保存的任务仍由 Windows 任务计划程序执行，不需要保持窗口打开。

“60 秒后测试”只执行一次。如果之前已启用每日计划，测试时仍会保留每日计划；界面上的时间和唤醒选项也会应用到每日计划。

## 停用与卸载

- 点击“停用并清除密码”，删除两个定时任务、保存的加密密码以及尚未完成的解锁请求。
- 双击 `Uninstall.cmd`，或打开开始菜单里的“卸载定时解锁”，删除本软件的登录组件、设置、任务和文件。
- 如果登录组件正被 Windows 使用，卸载会先取消注册并清除凭据，然后安排在重启时删除文件。卸载脚本会告知是否需要重启。

## 工作范围

| 场景 | 本版本行为 |
| --- | --- |
| 目标本地账户已经登录，按 Win + L 锁屏 | 到设定时间尝试解锁 |
| 到点时电脑已经在桌面 | 跳过 |
| 到点时登录的是另一个账户 | 跳过 |
| 电脑刚开机、没有用户登录 | 跳过 |
| 电脑已关机 | 不执行 |
| 电脑正在睡眠 | 勾选“允许唤醒”后请求唤醒；实际效果取决于硬件、电源计划及唤醒计时器设置 |
| 错过时间后才开机或恢复 | 不补执行 |
| Windows 拒绝了凭据 | 暂停后续自动解锁，直到重新保存设置 |
| Microsoft、Entra、AD 账户，远程桌面会话，ARM64 Windows | 本版本不支持 |

系统使用真实的账户密码验证身份；密码错误、账户锁定、密码过期及 Windows 登录策略仍会生效。

## 密码与请求处理

密码由 Windows DPAPI 以本机范围加密保存。配置所在的注册表项只允许 SYSTEM 和管理员访问；程序文件只允许 SYSTEM 和管理员修改。管理员拥有本机管理权限，因此这一方式不能用于向本机管理员隐藏密码。

密码不放在任务参数、命令行或状态信息中。界面先验证一次密码，再保存密文；登录组件提交前会使用 `CredProtectW` 保护序列化的密码。代码中的临时密码缓冲区在释放前会清零。

每次请求绑定当前控制台会话和本次设置的随机版本号，90 秒后失效。请求在提交凭据前被消耗，单个请求最多提交一次。更改设置、停用、切换账户或请求过期后，旧请求不能继续使用。

本软件只增加自己的登录组件，不注册凭据过滤器，也不删除或替换 Windows 自带的密码、PIN 等登录方式。

## 首次 Windows 验证

在虚拟机中先确认正常登录方式可用，然后分别验证：

1. 完整锁屏画面下的 60 秒测试；没有鼠标键盘操作也应返回原来的桌面。
2. 先按键进入密码登录画面，再执行同样的定时测试。
3. 到点时保持桌面解锁，程序应显示“已跳过”，不启动另一个登录会话。
4. 计划启用后点击“停用并清除密码”，再锁屏等待原计划时间，应保持锁屏。
5. 更换本地账户密码后，旧密码的自动验证失败应暂停；重新保存新密码后恢复。
6. 卸载后再次锁屏、登录和重启，正常登录应继续可用，软件任务应已删除。

如果测试没有自动解锁，可使用原来的登录方式进入桌面，打开设置并查看状态。若显示“请求已过期”，需要进一步检查该 Windows 版本下的锁屏组件加载和自动提交行为，不能把这次测试视为成功。

## 自行编译

需要 Visual Studio 2022 的“使用 C++ 的桌面开发”、Windows 11 SDK 和 CMake 3.24 或更高版本。在 Windows PowerShell 中运行：

```powershell
.\scripts\build.ps1
```

产物复制到 `bin`。发布程序使用静态 C++ 运行库，不需要安装 .NET。压缩包已包含 x64 的 `.exe` 和 `.dll`，普通试用无需自行编译。
